FUZZY SEARCH

Filter cards and collections as you type, with cached results across the full local database.

^N

PAGINATION

Big sets stay fast — results come in pages of 50, with Ctrl+N / Ctrl+P to move through them.

⌨

REBINDABLE KEYS

Every action — create, edit, delete, import, export, paging, queueing — can be rebound in the settings view. Persisted to .cardman.json.

▥

CONFIGURABLE COLUMNS

Toggle table columns (expansion, rarity, number, quantity) from the settings view to fit your terminal width.

^G

IMPORT QUEUE

Queue multiple sets for import inside the TUI (Ctrl+A to add, Ctrl+G to start) and watch progress live.

In & Out

Import an existing collection from CSV. Export to CSV for spreadsheets, plain text for humans, or PTCGO list format for Pokémon decks.

$ cardman collection import pokemon my_cards.csv
$ cardman collection export pokemon
Decks & Lists

Build decks per game from your collection. Lists are free-form groupings with color labels: wishlists, trade binders, set targets, whatever you need.

04

SOLO OR SHARED

Run it on your laptop, or put it on a server and let the whole playgroup ssh into their own collections.

LOCAL

single user

Everything in one portable cardman.db SQLite file in your working directory. No login prompt, no network needed after import.

local
$ cardman serve
  • Zero-config first run with a local user
  • Works completely offline once data is imported
  • Back up your collection by copying one file

SSH SERVER

multi user

A built-in SSH server (powered by Wish) serves the same TUI to remote clients, each with their own account.

ssh
# on the server
$ cardman serve-ssh

# from anywhere
$ ssh -p 2222 you@your-server
  • Email + bcrypt-hashed password accounts
  • ED25519 host key generated on first run
  • Docker & docker-compose files included
05

THE WHOLE CLI

The TUI is the front door, but everything is scriptable. Where you see <game>, pass pokemon, mtg, yugioh or onepiece.

core
cardman migrateapply database migrations
cardman servelaunch the TUI
cardman serve-sshstart the SSH server
cardman import-fullimport all Pokémon sets & cards
cardman import-updatesimport only sets you don't have
cardman import-sets <id…>import specific sets
cardman list-setslist sets available from the API
grouped · any game
cardman import all <game>full import for a game
cardman import new <game>incremental import
cardman cards list <game>browse the card database
cardman collection add <game> …add cards to your collection
cardman lists create <game> <name>create a custom list
cardman decks create <game> <name>create a deck

Run cardman --help or cardman <command> --help for the full reference, including collection import/export, lists add-card and decks add-card.

06

CONFIG IS A .ENV FILE

Six environment variables, all optional — sensible defaults cover the local single-user case. Drop a .env next to the binary or export them in your shell.

DB_DSN
SQLite DSN for the database · default file:cardman.db?_fk=1
LOG_LEVEL
log verbosity — DEBUG, INFO, WARN or ERROR · default INFO
SSH_PORT
listen port for serve-ssh · default 2222
SSH_HOST_KEY
path to the ED25519 host key (generated if missing) · default ~/.ssh/cardman_host_key
API_KEY
Pokémon TCG API key — optional, raises rate limits on import · default empty
CARDMAN_CONFIG
path to the local keybinding and theme config · default .cardman.json

Building from source? You'll need Go 1.25+ and a C compiler — SQLite support uses CGO: CGO_ENABLED=1 go build -o cardman ./cmd
